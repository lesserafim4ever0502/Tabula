# Tabula (MinimalTab) 🚀

一个专为效率极客设计的**极简、秒开、毛玻璃风格**浏览器起始页扩展。它可以彻底取代浏览器原生的空白页，提供沉浸式的搜索与书签管理体验。

## 🌟 核心特性

- **⚡ 秒开体验 (Zero Latency)**：通过 `preload.js` 同步渲染拦截，彻底消灭新建标签页时的“闪白”现象，背景色与壁纸瞬间加载。
- **🔮 现代美学 (Glassmorphism)**：深度应用毛玻璃虚化特效，支持自定义纯色背景或 Base64 压缩壁纸。
- **⌨️ 全键盘流 (Vim-style)**：
    - `j/k` 或 `↑/↓`：导航书签。
    - `/` 或 `Shift + 空格`：快速聚焦搜索框（并全选内容）。
    - `o`：后台静默打开。
    - `Enter/Delete`：快速编辑或删除。
- **🔍 智能搜索**：
    - 支持 Google/Bing/Baidu 及**自定义 URL 模板**。
    - 基于标题、URL 及自定义 Alias 的模糊匹配逻辑。
    - **书签多开**：支持用逗号隔开多个关键词（如 `x,yt,bi`），一键同时打开多个排名第一的书签。
- **📂 极简管理**：右侧抽屉式书签管理器，支持即时搜索过滤。
- **🔁 Odin 本地同步**：当 Odin 正在运行时，可通过 `http://127.0.0.1:29000` 将书签和 alias 同步到 Odin。该集成仅访问本机接口，不使用互联网服务。

## 📸 近期更新 (v1.x)

1. **设置面板重构**：统一 32px 高度标准，组件物理对齐，色块 100% 填充。
2. **微缩齿轮按钮**：底座半径减半 (24px)，图标微细化，视觉更克制。
3. **内嵌胶囊 Hover**：搜索结果展示页引入内嵌圆角胶囊悬浮态，层次感更强。

## 🛠️ 安装与使用

1. 打开浏览器扩展管理页面 (`chrome://extensions`)。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择项目根目录。
4. 使用 `Ctrl/Cmd + ,` 或点击左下角齿轮进入设置。
5. 如需同步到 Odin，请先保持 Odin 运行，然后进入 Settings → Data & Backup → Sync to Odin。
